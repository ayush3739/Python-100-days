# 🐍 Python 100 Days - Complete Learning Journey

A comprehensive collection of **83+ days** of Python programming projects and exercises, covering everything from beginner fundamentals to advanced web development, data science, automation, and more!

This repository documents my complete journey through Angela Yu's 100 Days of Python course. Each day includes hands-on projects, exercises, and real-world applications that progressively build programming skills from ground zero to professional-level Python development.

## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/Python-100-days.git
   cd Python-100-days
   ```

2. **Navigate to any project:**
   ```bash
   cd "Day 20-21"
   # or
   cd "PROJECTS/Snake game"
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt  # if available
   # or install manually as needed
   ```

4. **Run the project:**
   ```bash
   python main.py
   ```
