# Day 50 - Tinder Auto Swipe Bot

## Overview
This project is planned to be an automated Tinder swiping bot using Selenium WebDriver. The bot would automatically swipe right/left on Tinder profiles based on certain criteria.

## Project Status
⚠️ **ON HOLD** - This project is currently on hold for future development.

## Planned Features
- Automated login to Tinder
- Profile swiping automation (right/left swipes)
- Criteria-based swiping logic
- Match notification handling
- Chrome profile management for persistent sessions

## Technologies to be Used
- **Selenium WebDriver**: Browser automation
- **Python 3**: Programming language
- **Chrome WebDriver**: Chrome browser automation

## Planned Implementation
The bot would:
1. Log into Tinder using existing credentials
2. Navigate through profiles
3. Implement swiping logic based on preferences
4. Handle popups and notifications
5. Track matches and interactions
