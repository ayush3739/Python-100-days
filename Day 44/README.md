## 🎯 Topics Covered

### 1. CSS Box Model
- **Content**: The actual content of the element
- **Padding**: Space between content and border
- **Border**: Border around the element
- **Margin**: Space outside the border
- Box model properties: `width`, `height`, `padding`, `margin`, `border`

### 2. CSS Colors
- Named colors (e.g., `red`, `blue`, `black`)
- Hexadecimal colors (e.g., `#FF5733`)
- RGB colors (e.g., `rgb(255, 87, 51)`)
- RGBA colors with transparency (e.g., `rgba(255, 87, 51, 0.5)`)
- `color` property for text
- `background-color` property for backgrounds

### 3. Font Properties
- **`font-family`**: Specifying font families
- **`font-size`**: Controlling text size (px, em, rem, %)
- **`font-weight`**: Text boldness (normal, bold, 100-900)
- **`font-style`**: Italic, oblique, normal
- **`text-transform`**: Uppercase, lowercase, capitalize
- **`text-align`**: Text alignment (left, center, right, justify)
- Google Fonts integration

### 4. Layout and Positioning
- `width` and `height` properties
- Centering elements with margins
- `margin: auto` for horizontal centering
- Percentage-based layouts
