This folder contains HTML learning materials and projects covering essential HTML elements and concepts.

- **`anchor elements.html`** - Working with links and navigation

## 🎯 Topics Covered

### 1. HTML Document Structure
- HTML5 DOCTYPE declaration
- `<html>`, `<head>`, and `<body>` elements
- Basic document setup

### 2. Text Elements
- **Headings**: `<h1>`, `<h2>`, `<h3>` for hierarchical content
- Text formatting and semantic markup

### 3. Image Elements
- `<img>` tag with `src` and `alt` attributes
- External image linking
- Image accessibility with alt text

### 4. List Elements
- **Unordered lists**: `<ul>` with `<li>` items
- List structuring for organized content

### 5. Anchor Elements
- `<a>` tags for creating hyperlinks
- External link creation with `href` attribute
- Google Maps integration
