## 🎯 Topics Covered

### 1. Three Methods of Adding CSS
- **Inline CSS**: Styling directly within HTML elements using the `style` attribute
- **Internal CSS**: Using `<style>` tags within the HTML document's `<head>`
- **External CSS**: Linking separate `.css` files using `<link>` tags

### 2. CSS Selectors
- **Element Selector**: Target elements by their HTML tag name
- **Class Selector**: Target elements using the `.class` syntax
- **ID Selector**: Target unique elements using the `#id` syntax
- **Attribute Selector**: Target elements based on their attributes
- **Universal Selector**: Target all elements using `*`

### 3. CSS Properties
- Color styling with `color` property
- Text formatting and styling
- Basic layout and positioning
